CARA PUBLISH KE GITHUB PAGES:
1. Login ke https://github.com
2. Buat repository Public bernama USERNAME.github.io (ganti USERNAME dengan username GitHub).
3. Upload index.html dan folder assets (dengan isi keduanya) ke root repository.
4. Buka Settings > Pages.
5. Build and deployment: Deploy from a branch.
6. Branch: main; folder: /(root); Save.
7. Tunggu publikasi, lalu buka https://USERNAME.github.io
